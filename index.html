.NET 8 Microservices E-commerce

Development Environment Information

⚠️ Development Setup Required

This is a .NET 8 microservices application that requires Docker to run properly. The current development server is serving this information page as a placeholder.

🚀 Quick Start

To run the full microservices application, you need to set up the complete environment:

# Option 1: Use the automated PowerShell setup script ./setup.ps1
# Option 2: Manual Docker Compose setup cd src docker-compose -f docker-compose.yml -f docker-compose.override.yml up -d

Once running, access the Shopping Web UI at: http://localhost:6005

🏗️ Microservices Architecture

This application consists of multiple microservices communicating through an API Gateway:

🛍️ Shopping Web UI

ASP.NET Core Razor Pages frontend

Port: 6005

🚪 API Gateway

YARP Reverse Proxy for routing

Port: 6004

📦 Catalog API

Product catalog management

Port: 6000

🛒 Basket API

Shopping cart management

Port: 6001

💰 Discount gRPC

Discount calculation service

Port: 6002

📋 Ordering API

Order processing with DDD/CQRS

Port: 6003

🛠️ Prerequisites

  • ✅ Docker Desktop - Required for running all microservices
  • ✅ .NET 8 SDK - For local development and building
  • ✅ Visual Studio 2022 or VS Code - Recommended IDE

🔧 Available Services

When the application is running, these services will be available:

  • Shopping Web UI: http://localhost:6005
  • API Gateway: http://localhost:6004
  • RabbitMQ Management: http://localhost:15672 (guest/guest)
  • Health Checks: Available on each API endpoint
